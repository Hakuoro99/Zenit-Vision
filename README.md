# Zenit-Visión

Bienvenido al repositorio del proyecto de tesis **Zenit-Visión**.

## Descripción

Este repositorio contiene el código fuente para el sistema de visión del proyecto Zenit.

## Estructura preliminar

- `main.py`: Archivo principal de ejecución del proyecto.

## Cómo ejecutar

Asegúrate de tener Python instalado y ejecuta:

```bash
python main.py
```
